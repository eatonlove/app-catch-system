# 应用机会选品系统：方案落地与使用说明 v4

基于《应用机会选品系统-研究与功能架构方案.md》，延续腾讯轻量云 Web/API/PostgreSQL + 第三方大模型 + Mac mini 本地采集。此版本补齐人工可操作的选品决策闭环；未接通的外部自动采集与需要成熟样本的算法能力单列，不把表单入口写成自动数据源。

## 现在怎么使用

1. **采集计划**：选择渠道/日期，采集一次或每日采集。任务详情可检索应用、查看原始字段。失败或部分完成可另建重试，原批次保留。
2. **数据与规则 → 证据库**：登记或导入评论、当地关键词搜索、功能观察、访谈、成本及资格依据。每条有原文、国家、渠道、日期、来源、使用范围、质量及哈希。关键词量未知保持未知。
3. **机会研究**：勾选完整采集批次和补充证据，查看实际AI输入。13个提示词方向覆盖方案十条发现路线，另含综合/资格/MVP等视角。选择方向后调用现有模型，提示词和数据范围冻结。
4. **报告 → 保存到机会池**：把某条AI假设保存为独立机会，明确目标国家和渠道；不会把竞品应用直接当作商业机会。相同报告候选/目标市场重复保存去重。
5. **机会池 → 查看机会**：填写人群、任务、场景、差异化、替代品、反证、具体功能和MVP。证据不足时在补证池，用“影响×可改变决策程度÷验证人时”排列。高收入也不能抵消资格排除。
6. **数据与规则 → 资格规则库**：先登记有来源的规则，再在机会中做“行业可进入性＋渠道准备状态”审核。可进入必须有实际功能事实和未过期适用规则；READY另需基础材料路径。功能/分项更新会清除旧放行，最长30天需复核。
7. **填写分项证据**：录入M/D/G/S/P/A/B和证据依据；P/A/B使用0/25/50/75/100锚点。质量不得超过原证据，日期不得晚于事实日期，同信号族不得重复计分。需求/供给/获客须有目标国家证据，供给还需完整搜索证据。此处是人工证据评分；市场分位自动取值尚需真实参考集，不声称已自动计算。
8. **保存今天评分快照**：固定机会内容、版本、审核、公式和因子；以后从下拉框查看相同版本。保存每因子权重±20%后的情景，属于敏感性分析，不是统计置信区间。拒绝用今天输入生成过去时点的“回测”。
9. **创建验证实验**：从机会详情建立E0–E4计划，预设分母、最低样本、预算、截止日、负责人和停止条件。系统不自动投广告、联系用户或收费。
10. **验证实验 → 追加真实结果**：录入观察窗、付款/退款用户、收入和成本、归因与证据。计算付款比例、Wilson95%区间、退款率、净收入及贡献。净收入不重复扣费；未成熟窗口不输出续费率。
11. **更新决策阶段**：人工决定补证/验证/暂存/排除。立项要求主榜证据门槛、READY、MVP范围和成熟真实付费、非负贡献结果，不由AI或分数单独批准。所有修改追加历史并防止旧页面覆盖新版本。

## 评分口径

权重 M .20 / D .15 / G .15 / S .15 / P .10 / A .15 / B .10。

有效权重c；Q为有效因子加权质量，F为按事实日期与正常延迟计算的指数新鲜度，E为实体可信度，L为当地证据充分度。

C=.30c+.25Q+.20F+.15E+.10L。
Raw=Σ(w×分数)/c；Adjusted=max(0,Raw×(.5+.5C)−Penalty)。权重/阈值为未校准v1假设，不是成功概率。

以下情形不进入值得验证主榜：资格待审/排除、渠道未知/不可发行、规则过期、c<.70、M/D/A缺证、C<.65、增长轨缺中期、关键证据超过30天更新期限。严格模式额外要求READY。明确排除或不可发行的adjusted=null，不是0分。

正式分池为值得验证、补证/新品、适合立项；另有排除与暂存。探索分与机会分不混算。自动因子参考集、跨语言聚类和业务回测的剩余能力见专项待办文档。

## 导入与指标历史

支持UTF-8 CSV和JSON，预览→错误/样例→确认。每批最多1000行或1MB页面文件。CSV列映射为原列名→标准列名；公共字段可一次填写，证据ID多值以 `|` 分隔。XLSX先另存CSV。

- evidence：评论/检索/访谈等，模板字段可在导入窗口下载，或直接使用中文表单。
- observations：listing_key/country/store/device/metric/date/value/unit/currency/basis/scope/source/period/is_estimate/source_revision/missing_reason/evidence_ids。money明确币种，daily才进入增长；null需原因。每次真实修订保留，计算使用最新采集版本。供应商修订须填source_revision；同值的重新发布也可借不同修订号保留，完全重复内容不双计。
- bundle：现有采集详情导出的完整点点schema1 JSON。保留真实来源、context及context_verified；部分数据保持PARTIAL。

7/28/90日增长分别比较相邻完整窗口，至少90%观测覆盖；缺日不补0。不同国家/商店/设备/指标/单位/币种/净毛/范围/来源分别计算。负收入和低基数明确标记；未取得收入不会由排名推算。没有自动调用未授权商业API。

## 部署与兼容

新增 ac_lab_records 与 ac_lab_history 两表，使用本项目独立PostgreSQL；原任务、结果、报告和反馈表不改结构、不删除数据。所有新接口复用管理员会话/Bearer及CSRF机制，模型/采集令牌不下发页面。

Mac采集协议不变，现有节点可以继续工作。仓库同步后Mac上的Codex可按现有MAC_MINI_HANDOFF.md更新；本次云端模块不要求重新配置点点账号或重置登录。

## 验证边界

本地测试数据仅在一次性/本地数据库。生产只做读取与页面资源核验，不为测试制造机会或实验。验收包括：接口认证、资格/立项门槛、版本冲突、规则与证据约束、导入幂等和修订、真实模型输入快照、评分固定回放、实验分母/净收入口径、PostgreSQL写入与备份恢复。

需要真实时间或外部权限的验收绝不标为已完成，集中放在《未来待补充能力与数据.md》。
